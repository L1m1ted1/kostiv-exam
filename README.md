# DevOps Exam Project

Даний репозиторій містить комплексний проект з автоматизації інфраструктури та розгортання додатку, розділений на три основні етапи (Tasks). Проект реалізований як частина екзаменаційної роботи. 
Поточна Ip-адреса віртуальної машини: http://159.65.122.92

## 🏗 Структура проекту

- **[task1](./task1/)**: Terraform конфігурації для створення хмарної інфраструктури.
- **[task2](./task2/)**: Ansible Playbook для налаштування середовища Kubernetes (Minikube).
- **[task3](./task3/)**: Конфігураційні файли Helm (Values) та GitHub Actions workflow для CI/CD.

---

## 🛠 Task 1: Робота з Terraform

Ця частина проекту відповідає за створення базової інфраструктури в хмарі **DigitalOcean**.

### Створювані ресурси:
- **VPC**: Віртуальна приватна хмара для ізоляції ресурсів.
- **Droplet (Node)**: Віртуальна машина на базі Ubuntu 24.04 (s-2vcpu-4gb).
- **Firewall**: Налаштовані правила доступу (SSH, HTTP, HTTPS, порти 8000-8003).
- **Spaces Bucket**: Об'єктне сховище для даних.

---

## 📜 Task 2: Конфігурування за допомогою Ansible

Ansible Playbook автоматизує процес підготовки сервера до запуску контейнеризованих додатків.

### Основні кроки:
- Встановлення Docker Engine.
- Встановлення та налаштування Minikube.
- Встановлення Kubectl та Helm 3.
- Налаштування `kubectl proxy` як системного сервісу (systemd).
- Перевірка версій встановленого ПЗ.

---

## 🚀 Task 3: CI/CD та розгортання в Kubernetes

Автоматизація побудована на базі **GitHub Actions**. Процес розділений на два ключові етапи: **Build** та **Deploy**.

### Workflow: `task3-deploy.yml`
1. **Build and Push**:
   - Клонування коду додатку з зовнішнього репозиторію.
   - Збірка Docker образу.
   - Тегування образу: `develop` (для Dev) та `1.0.0` (для Release).
   - Пуш образу до Docker Hub.

2. **Deploy**:
   - Розгортання в Minikube через Helm.
   - Створення окремих Namespace для кожного середовища.
   - Налаштування Port-forwarding для забезпечення зовнішнього доступу.

### Середовища розгортання:
| Environment | Port | Image Tag | Values File |
| :--- | :--- | :--- | :--- |
| **Dev** | 8002 | `develop` | `values-dev.yml` |
| **Release** | 8003 | `1.0.0` | `values-release.yml` |

## 🔑 Необхідні секрети (GitHub Secrets)

Для коректної роботи GitHub Actions необхідно додати наступні секрети:
- `DOCKERHUB_USERNAME`: Логін до Docker Hub.
- `DOCKERHUB_TOKEN`: Токен або пароль до Docker Hub.
- `VM_PASSWORD`: Пароль від root-користувача віртуальної машини.
